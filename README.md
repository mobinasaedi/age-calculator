# Age Calculator

A simple Python project that calculates a person's age in years, months, and days, and estimates the total number of months, days, hours, and seconds lived.

## Features
- Accepts age or date of birth as input
- Calculates age in years, months, and days
- Converts days into hours and seconds
- Uses Python functions, loops, conditionals, and lists

## Technologies
- Python
- datetime module

## How to Run

```bash
python age_calculator.py
```

## Note
The current implementation uses an approximate method to calculate total days. Exact date-difference calculations can be implemented using Python's `datetime` module.
